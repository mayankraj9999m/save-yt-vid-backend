# Save YT Video (Backend)

The Node.js/Express backend service for the Save YT Video app. It handles downloading and streaming progress using `yt-dlp`.

## Features
- **Video Processing:** Extracts metadata, audio, and video formats from YouTube links.
- **Real-time Progress:** Uses Server-Sent Events (SSE) to stream download progress and ETA to the client.
- **Process Management:** Allows pausing, resuming, and cancelling active downloads safely.

## Prerequisites
Before running the backend, ensure you have the following installed on your system:
- **Node.js** (v16 or higher recommended).
- **yt-dlp**: Required for downloading and extracting video formats. It must be accessible in your system's `PATH`. ([Installation Guide](https://github.com/yt-dlp/yt-dlp/wiki/Installation))
- **FFmpeg**: Required by `yt-dlp` to merge separate audio and video streams in the highest quality. It must also be accessible in your system's `PATH`.

## Setup & Running Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev:server
   ```
   *The API will start on `http://localhost:3000` by default.*

## REST API Documentation

### `GET /api/formats`
Returns a list of available audio and video formats for a given YouTube URL.
- **Query Params:** 
  - `url` (string): The YouTube URL to process.

### `GET /api/metadata`
Returns video metadata (title, duration, thumbnail) and estimated file size based on the chosen quality.
- **Query Params:** 
  - `url` (string): The YouTube URL.
  - `mode` (string): Download mode, one of `OPTIMAL`, `BEST`, or `CUSTOM`.
  - `customFormat` (string): *Optional.* Specific format ID if `mode=CUSTOM`.

### `GET /api/download`
Initiates the download process. This endpoint keeps the connection open and streams progress updates to the client using **Server-Sent Events (SSE)**.
- **Query Params:** 
  - `url` (string): The YouTube URL.
  - `mode` (string): Download mode (`OPTIMAL`, `BEST`, `CUSTOM`).
  - `id` (string): A unique identifier generated by the frontend for this download session.
  - `customLocation` (string): *Optional.* Absolute path to save the video locally.

### `POST /api/download/pause`
Stops the active download process. Because `yt-dlp` keeps `.part` files, you can "resume" by simply calling the `/api/download` route again with the exact same URL and location parameters.
- **Body (JSON):** 
  - `{ "id": "<download_id>" }`

### `POST /api/download/cancel`
Cancels the active download completely and stops the background `yt-dlp` process.
- **Body (JSON):** 
  - `{ "id": "<download_id>" }`
